Crate fabric_writer 

Source
Expand description

CLI tool for scaffolding Fabric Minecraft mods.

fabric-writer delegates to the official Fabric CLI (fabric init) to create the project structure, then tracks generated content in .fw/fabric-writer.yml so subsequent commands can regenerate Java sources.

Typical workflow:

fw init --name MyMod --version 26.2 --java-path /path/to/jdk
fw add item --id my_item
fw add block --id my_block
fw regen
fw status
