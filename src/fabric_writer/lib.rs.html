3//! CLI tool for scaffolding Fabric Minecraft mods.
4//!
5//! `fabric-writer` delegates to the official Fabric CLI (`fabric init`) to create
6//! the project structure, then tracks generated content in
7//! `.fw/fabric-writer.yml` so subsequent commands can regenerate Java sources.
8//!
9//! Typical workflow:
10//!
11//! ```text
12//! fw init --name MyMod --version 26.2 --java-path /path/to/jdk
13//! fw add item --id my_item
14//! fw add block --id my_block
15//! fw regen
16//! fw status
17//! ```
18

21/// LazyLock-based Java import helpers for genco templates.
